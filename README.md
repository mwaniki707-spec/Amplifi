# Amplifi

A digital agency landing site for Amplifi — built with React, TanStack Start, TypeScript, and Tailwind CSS.

## Development

You need Node.js and npm installed.

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

## Build

```sh
npm run build
```

## Deploy

```sh
firebase deploy --only hosting
```

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS
